# T-001 — Establish the classroom MVP foundation

State: proposed  
Owner: Dallas  
Priority: P0  
Depends on: —  
Area: product, architecture, validation

## Objective

Turn the empty repository into a validated, documented starting point for Prophets or Princesses.

## Scope

- Define the teacher and student workflows.
- Define the initial quote and question model.
- Define the game phases and scoring invariants.
- Create a small verified content sample.
- Choose the implementation stack.
- Create the initial app shell and test setup after the plan is approved.

## Out of scope

- Public quote marketplace
- Payments
- Native mobile apps
- AI-generated playable quotes
- Student accounts
- Teams and advanced animations
- Commercial distribution

## Acceptance criteria

- [ ] The project docs describe the source of truth for quote accuracy.
- [ ] A teacher can explain the quote-entry workflow.
- [ ] The confidence and power-up timing rules are unambiguous.
- [ ] The first five question types are documented.
- [ ] A 10-15 quote content sample exists and is reviewed.
- [ ] The app stack is recorded.
- [ ] The first implementation task can be started without unresolved architecture questions.

## Risks

- Copyright or permission issues with exact movie and Church quotations.
- Ambiguous or misattributed quotations.
- Power-ups overpowering knowledge or making rankings feel unfair.
- Realtime synchronization being attempted before scoring works locally.
- Teacher authoring taking longer than playing the game.

## Verification plan

- Test the paper/static question set with classmates.
- Unit-test confidence and power-up calculations.
- Manually run a complete game from teacher setup through results.
- Record content review decisions before adding a public quote library.
