# T-002 — Build teacher quote authoring

State: proposed  
Owner: Dallas  
Priority: P0  
Depends on: T-001  
Area: content, frontend, domain

## Objective

Let a teacher enter one verified quote and review generated question variations before publishing it to a quote pack.

## Scope

- Establish the Next.js and TypeScript app shell.
- Add canonical quote and question validation schemas.
- Build quote-entry form.
- Generate editable question drafts from one quote record.
- Allow the teacher to enable or disable each draft.
- Clearly mark drafts as teacher-reviewed or unreviewed.
- Add unit tests for validation and generation.

## Out of scope

- Supabase persistence
- Teacher authentication
- Realtime games
- AI-generated quotations
- Public quote library
- Student accounts

## Acceptance criteria

- [ ] A teacher can enter required quote fields.
- [ ] Optional explanation and theme fields can be empty.
- [ ] Invalid years, categories, and source types are rejected.
- [ ] The app generates the initial question types from one quote.
- [ ] Generated answer options are editable.
- [ ] A question cannot become playable until reviewed.
- [ ] Unit tests cover the domain rules.
- [ ] The app runs locally using documented commands.

## Verification plan

- Run formatting, type checking, and unit tests.
- Manually create one quote and inspect every generated question.
- Verify that an unreviewed draft cannot be started in a game.
