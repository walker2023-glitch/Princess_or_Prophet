# T-004 — Persist quote packs and build teacher game setup

State: in-progress
Owner: Dallas
Priority: P0
Depends on: T-003
Area: data, authentication, frontend, security

## Objective

Allow a teacher to sign in, create and save quote packs, reopen them later, and create a classroom game configuration from a saved pack.

## Scope

- Supabase schema and row-level security.
- Teacher sign-in and sign-up.
- Local fallback when Supabase variables are absent.
- Quote-pack repository.
- Game repository and join-code generation.
- Teacher dashboard.
- Persistent quote creation flow.
- Unit tests and build verification.

## Out of scope

- Realtime multiplayer.
- Student accounts.
- Payments.
- AI-generated quotations.
- Public quote marketplace.
- Production server-side route protection.

## Acceptance criteria

- [ ] A teacher can sign up or sign in.
- [ ] A teacher can create a quote pack and save it.
- [ ] Saved quote packs appear on the teacher dashboard.
- [ ] A teacher can create a game configuration from a saved pack.
- [ ] Game creation rejects packs without reviewed questions.
- [ ] Local mode works without Supabase variables.
- [ ] Database policies restrict private records by owner.
- [ ] No secret key is exposed in browser code.
- [ ] Tests pass.
- [ ] Production build passes.
