# T-003 — Build the student gameplay prototype

State: in-progress
Owner: Dallas
Priority: P0
Depends on: T-002
Area: frontend, game-domain, UX

## Objective

Create a local/mock student experience that demonstrates the complete gameplay loop using the Stitch-inspired visual direction.

## Scope

- Student join screen and waiting room.
- State-driven power-up selection.
- Mock question and answer flow.
- Confidence slider and scoring.
- Answer lock and reveal screens.
- Leaderboard and catch-up notification.
- Final results screen.
- Responsive original visual styling.
- Unit tests for state transitions and game rules.

## Out of scope

- Supabase persistence.
- Authentication.
- Realtime multiplayer.
- Teacher host controls.
- Production quote library.
- Public launch.

## Acceptance criteria

- [ ] Student can join with a nickname and racer token.
- [ ] Student can move through every gameplay state.
- [ ] Student can reserve and use a power-up once.
- [ ] Power-up effects are visible before answer lock.
- [ ] Confidence is locked before reveal.
- [ ] Correct answers use the existing confidence scoring rules.
- [ ] The student remains visible in leaderboard results.
- [ ] Catch-up feedback is positive and understandable.
- [ ] Layout works on narrow screens and classroom displays.
- [ ] Unit tests cover state transitions.
- [ ] Production build passes.

## Verification plan

- Run npm test.
- Run npm run build.
- Open /play and complete at least one correct and one incorrect path.
- Test all four power-ups.
- Check keyboard focus and narrow-screen layout.
- Review the result against the attached Stitch prototype.
