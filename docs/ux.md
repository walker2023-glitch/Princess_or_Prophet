# UX Plan

## Teacher experience

The teacher should be able to create playable content quickly.

### Quote authoring

1. Click New Quote.
2. Paste or type the quote.
3. Enter speaker, category, year, source, and link.
4. Optionally add an explanation and theme.
5. Click Generate Question Variations.
6. Review, edit, enable, or disable the drafts.
7. Save the quote to a pack.

The teacher must enter the quote once. Generated distractors should be editable and must never be treated as verified automatically.

### Game hosting

- Select a quote pack.
- Choose number of questions and time limit.
- Choose whether confidence wagers are enabled.
- Choose whether catch-up power-ups are enabled.
- Display a join code.
- Start, pause, skip, or advance questions.
- Show answer explanations and discussion prompts.
- End the game and view learning results.

## Student experience

1. Enter the game code.
2. Choose a temporary nickname.
3. Wait in the lobby.
4. Before each question, choose whether to reserve a power-up.
5. Read the question.
6. Activate an eligible power-up if desired.
7. Select an answer.
8. Set confidence from 1-10.
9. Lock the response before reveal.
10. See correctness, explanation, points, and updated position.

## Timing rules

- Help power-ups may be reserved before the question and activated before answer lock.
- Confidence must be submitted before reveal.
- Score or protection power-ups may be used after the question opens but before reveal.
- No power-up may change the answer after the reveal.
- If a student disconnects, the server preserves the last valid state and allows rejoin with the game code.

## Accessibility

- Do not rely on color alone for answer choices.
- Use keyboard-accessible controls.
- Make timer state available in text, not only animation.
- Keep quote text readable on phones.
- Respect reduced-motion preferences.
- Make the confidence slider usable with keyboard arrows and touch.

## Tone

The game should feel energetic and playful, but not mock religious figures or fictional characters. The learning reveal should be calm and informative after the competitive answer phase.
