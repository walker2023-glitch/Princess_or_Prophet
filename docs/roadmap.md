# Roadmap

## Phase 0 — Planning and content proof

Goal: prove that the game is enjoyable and the content is teachable.

- Create 10-15 manually verified quotes.
- Make one paper or static prototype.
- Test question types with classmates.
- Decide which question types are genuinely useful.
- Confirm that teachers can enter a quote without frustration.

Exit criteria:

- Students understand the game without extensive explanation.
- At least one teacher would use a 15-minute version.
- The quote/source review process is clear.

## Phase 1 — Content authoring

Goal: a teacher can create a verified quote pack.

- Teacher authentication.
- Quote-pack CRUD.
- Quote-entry form.
- Question variation generation.
- Editable answer options.
- Verification status and source link.
- Unit tests for validation.

## Phase 2 — Single-player game

Goal: validate scoring before realtime complexity.

- Question renderer.
- Five initial question types.
- Confidence slider.
- Score calculation.
- Power-up inventory.
- Catch-up calculation.
- Reveal/explanation screen.
- Learning summary.

## Phase 3 — Realtime classroom MVP

Goal: one teacher can run a live class.

- Game creation and join codes.
- Student nickname joining.
- Server-authoritative phase machine.
- Realtime question delivery.
- Answer submission.
- Reconnect behavior.
- Teacher controls.
- Live scoreboard.
- Playwright multi-context test.

## Phase 4 — Classroom polish

- Team mode.
- Better animations.
- Discussion prompts.
- Results export.
- Quote-pack duplication.
- Import from CSV.
- Better mobile layout.
- Error recovery and monitoring.

## Phase 5 — Optional AI assistance

AI may suggest themes, explanations, distractors, discussion questions, and suspicious quote warnings.

AI may not publish or verify quotations automatically. Every AI-assisted item requires teacher review.
